# Astrolabe

Calculators for the game Stellar Odyssey (Steam realm), as a web page:
https://johnnyboyqc.github.io/Astrolabe/

This repository holds only the published page (`index.html`, `version.json`, `login.html`).
The Tampermonkey userscript that used to live here is no longer updated; the web page replaces it.
Astrolabe only shows information: it never plays the game for you.
